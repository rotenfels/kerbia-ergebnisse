# kerbia-ergebnisse

Öffentliche Ergebnisdatei für die App Kerbia von Rotenfels Studio.

`ergebnisse.json` ist ein signierter Umschlag (`kerbia.results-signed/1`, Ed25519). Die App prüft die Signatur vor jeder Übernahme; unsignierte oder veränderte Dateien werden verworfen.

Hier liegen keine persönlichen Daten.
